# TMT池 日频技术面看板

TMT池个股（含指数、部分港股）日频行情技术面速览：涨跌幅、换手率、放量、5/20/60日均线位置、阶段高点回撤。

**更新频率：** 每个交易日
**状态：** 已上线

---

## 说明

- 数据源为内部维护的 TMT 池日频行情（收盘价/换手率/成交额），不在本仓库中公开
- 每只标的按自身换手率非0筛选真实交易日序列，剔除非交易日的横向填充价；港股与A股假期不同步的标的会标注具体数据日期
- "阶段新高/阶段高点回撤"指数据起始日以来的区间最高价，非严格意义上的52周新高（数据长度不足52周时的近似）
- 仅发布最终看板（`dashboard/latest.html`），不包含原始数据与生成脚本
