🔬 技术路线科普：LPO / NPO / CPO▾
一句话主线：三条路线都在解决同一个问题——AI 算力指数级增长，光互联的「功耗 / 时延 / 密度」成为瓶颈。解法是让光电转换点不断靠近交换芯片（ASIC），缩短高速电信号在 PCB 上的走线、去掉耗电的 DSP。代价是可维护性变差、制造难度上升。 本质是一道「省功耗 ↔ 可插拔/易维护 ↔ 量产成熟度」的三角取舍。

🖼 结构图详解：光引擎放在哪里，决定了一切
原始架构图来源：SemiAnalysis《Co-Packaged Optics (CPO) – Scaling with Light》（2026-01）｜ 配中文解读
① 传统可插拔 Pluggable —— 电信号要走 15-30cm 长铜走线到面板
交换芯片（Switch ASIC）的电信号要经 Substrate → Host PCB 上的铜走线（Copper Trace）走 15-30cm，再经 QSFP 连接器进到面板上的可插拔模块（Transceiver），在模块里完成光电转换、接光纤。走线长 → 信号衰减大 → 需要大功率长距 SerDes 和 DSP 来补偿。优点是模块可热插拔、易维护、标准化。
📍 这里 MPO 在哪？可插拔的对外光口（LC 或 MPO）在模块前脸（图中 Fiber 引出处）——光缆跳线直接插在模块正面。注意图里的「QSFP Connector」是电接口（模块金手指插进面板笼子），不是光口，别混淆。
② 拆开一个 DSP 模块 —— LPO 干的事就是「删掉那颗橙色 DSP」
模块里的光引擎（OE）＝发射侧 TOSA（Driver 驱动 + Laser/Modulator 激光器/调制器）＋ 接收侧 ROSA（Photodetector 光电探测器 + TIA 跨阻放大器）。右边橙色的 Optical DSP 负责重定时、纠错、信号恢复——但它吃掉整个模块约 50% 的功耗、20-30% 的 BOM 成本，是「头号公敌」。
核心变化：LPO（线性直驱）＝去掉这颗 DSP，由交换芯片 SerDes 直接线性驱动光器件，形态仍是标准可插拔。
优势：单模块功耗约降 50%（省掉 DSP 4-7W）、时延更低、BOM 与成本下降，且沿用现有可插拔生态、改动最小。
挑战：无 DSP 纠错/均衡 → 对信道完整性、激光器线性度要求高，传输距离受限（主打 DR 短距）；交换芯片与光模块需协同认证，互操作性是门槛。变体 LRO（接收侧保留 retimer）。
节奏：OFC 持续送样，2025-2026 小批量，云厂主推短距场景。
对 A 股：同形态、国产模块厂可直接做（旭创/新易盛/天孚）。注意 DSP 原由博通/Marvell 外购，去 DSP 对国产厂 BOM/毛利的净影响需跟踪。
❓ 没了 DSP 为什么还能跑？谁接手了它的活？价值量会因此增加吗？
DSP 原来干 4 件事：重定时（CDR）、均衡（补偿信道损耗/ISI）、纠错（FEC）、PAM4 编码。LPO 不是让这些活消失，而是重新分配 + 靠更好的信道少干活：
· 均衡 → 交换芯片 SerDes + 模块内 Driver/TIA 接手：交换 ASIC 的 SerDes 本身就带强大的均衡能力，LPO 让它直接线性驱动光器件，这部分活由 SerDes 扛；模块内的 Driver、TIA 也升级为带模拟均衡（linear EQ）的高线性度版本。
· 纠错 FEC → 留在交换芯片：FEC 本就是端到端、锚在交换/网卡的 MAC/PHY 里，不依赖模块 DSP。
· 靠短距：LPO 主打 DR 短距，信道损耗小，本来就不需要 DSP 那么强的补偿——「信道够好的地方才用」。
价值量会因此增加吗？——不是简单的"增加"，而是结构迁移：
· DSP 占可插拔模块 BOM 约 30%、且是国产模块厂外购（Marvell/Inphi）→ 去掉后模块整体 BOM/ASP 下降。
· 接手 DSP 工作的大头是交换芯片 SerDes（博通/Marvell/英伟达，A 股进不去）→ 价值往交换芯片迁移；模块内 Driver/TIA 价值占比上升（要求更高、更线性），但绝对量小、也多为外购 IC。
对国产模块厂（旭创/新易盛）：单模块收入 ↓（丢了 DSP 转手收入），但毛利率可能 ↑（去掉低毛利外购件）+ 技术壁垒 ↑（线性设计、与交换芯片协同认证更难）。→ 是「毛利结构 + 壁垒」的故事，不是单纯价值量增加，净影响需跟踪。
③ NPO 近封装 —— 光引擎做成「可拆的独立基板」，挪到 ASIC 旁边
核心变化：光引擎（PIC 光子芯片 + EIC 电芯片）不直接坐在 ASIC 基板上，而是做成独立的 Engine Substrate、通过 socket 可拆卸，紧挨 ASIC。电信号仍经一小段铜通道到光引擎，但远短于面板可插拔；激光器外置（Remote Laser Source），光纤经 FAU 耦合出来。
优势：走线短 → 功耗、信号完整性优于可插拔；是迈向 CPO 的工程过渡，制造难度低于 CPO，且 OE 可拆卸、维护性好于 CPO。
挑战：不可插拔或半可插拔，可维护性较可插拔下降；标准化弱，更多是定制方案。
节奏：博通等早有 NPO 方案，本测算表中 AWS 6.4T NPO 2027 放量约 1000 万只，是中期重要增量。
对 A 股：旭创/新易盛模型已新增 6.4T NPO 收入（旭创 +710 亿、新易盛 +426 亿），光引擎利好天孚。
❓ 为什么前面可插拔图里没有、NPO/CPO 图里却冒出了 FAU 和外置光源？
核心原因：可插拔时代，激光器和光纤耦合这两件事都被"藏"在密封的模块内部（模块厂出厂时就做好了），示意图上只画一根光纤从模块出来。一旦进入 NPO/CPO，面板模块消失、光引擎变成裸露在基板上的芯片，这两件原本封在模块里的事就必须拿到系统层面显式处理，于是图里多出来：
· 外置光源（ELS / Remote Laser Source）：硅光的 PIC 自己不发光（硅是间接带隙），必须靠 III-V（InP）激光器供光。而激光器又是最易失效、最怕热的器件——若集成进紧挨高温 ASIC 的光引擎，一旦损坏会拖垮整颗芯片（blast radius 大）。所以业界共识是把激光器做成独立、可插拔的外置模块，用光纤喂给光引擎、坏了能单独换。→ 利好 CW DFB 光源（源杰）。
· FAU（Fiber Array Unit，光纤阵列单元）：可插拔模块里，光纤与芯片的耦合用预对准的标准化连接器、在模块内部完成。到了 CPO，光纤要直接亚微米级对准到 PIC 上的波导/光栅耦合器，这道工序靠一个 FAU（玻璃块，精确固定光纤阵列）完成，并做成可拆卸以便换纤。耦合点从"模块内"挪到了"光引擎上"，FAU 就成了显式的关键部件。→ 利好 FAU/光器件（天孚）、连接器（太辰光）。
一句话：可插拔把激光器和耦合都封在模块里看不见；CPO 把模块拆开，这两件事就暴露成了独立的系统级部件。
④ CPO 共封装 —— 光引擎与 ASIC 同坐一块基板，电走线只剩 ~10mm
核心变化：光引擎与 Switch ASIC 共封装在同一块 ASIC Substrate 上、间距仅约 10mm（对比可插拔的 150-300mm），彻底取消面板可插拔模块，基于硅光。电走线缩到最短 → DSP 可彻底取消、改用短距 SerDes 甚至 Wide I/O。光引擎初期放在 substrate，未来上移到 interposer。
📍 MPO 在哪？本图（及上方 NPO 图）最右的「Connector」就是交换机面板的 MPO/LC 光连接器——机内光纤从 FAU 一路引到面板，在这里经 MPO（内含 MT 插芯、一个连接器接多芯光纤）对外接光缆。英伟达 Quantum-X 即有 144 个物理 MPO 端口。利好太辰光/致尚。
优势：功耗最低、密度/带宽最高，是 AI 大规模组网的终极形态方向。
挑战：良率/制造难、热管理复杂、可维护性差（光器件坏需换整机）、标准化早期；激光器必须外置（External Laser Source / ELS）以便维护。
节奏：英伟达 Quantum-X / Spectrum-X、博通 CPO 交换机 2026-2027 导入，先在交换机侧落地，与可插拔长期共存。
对 A 股：外置 CW 光源大幅利好源杰；光引擎/封装利好天孚；无源/连接器利好腾景、太辰光、致尚。对旭创/新易盛是中长期形态变化点。
🔆 光引擎（Optical Engine, OE）到底是什么？
贯穿可插拔 / NPO / CPO 的「干活核心」——上面四张图里反复出现的那个东西
定义：光引擎是光模块/CPO 里完成电↔光转换的核心功能单元。发射侧：Driver 驱动 Modulator/Laser 把电信号变成光；接收侧：Photodetector（PD）收光、TIA 放大还原成电。无论可插拔、NPO 还是 CPO，光引擎都是那颗"干活的核心"，区别只在于它放在哪、怎么集成（前面板模块内 → ASIC 旁 → ASIC 同封装内）。
🔗 和"硅光模块"什么关系？——别把两个轴混了。光引擎有两个正交的轴：「用什么做」（EML 分立 / 硅光 PIC / TFLN，技术轴）× 「放在哪」（可插拔 / NPO / CPO，位置轴）。CPO/NPO 的光引擎本质就是一颗硅光 PIC，和光芯片章节里"硅光模块"用的那颗同源——区别只是把它从可插拔位置搬到 ASIC 旁 / 封装内、并去掉 DSP。所以：硅光 ≠ CPO——硅光是"引擎用什么材料"，CPO 是"引擎放哪"；硅光模块＝硅光引擎 + 可插拔位置，CPO＝（通常也是）硅光引擎 + 共封装位置。

🧬 光芯片技术详解：EML / CW / InP（光引擎里的"心脏"）▾
承上启下：前面讲的是光引擎放在哪（可插拔/NPO/CPO 的封装结构）。这一节往里看一层——光引擎里真正做电↔光转换的"心脏"就是光芯片。下面按四个问题展开：① 光模块和光芯片什么关系 → ② EML 和 CW 到底差在哪 → ③ 速率由什么决定 → ④ InP 在其中扮演什么角色。
① 光模块 ↔ 光芯片：整机 → 部件 → 零件
光芯片是光模块里最关键的核心元器件，承担光电转换：发射端激光器芯片把电变光、接收端探测器芯片把光变电。它是模块性能、速率、成本的决定性环节——激光器芯片占传统 800G 模块成本约 21%，其中 EML 芯片占模块 BOM 30% 以上（硅光模块里激光器占比约 9%）。
图：激光器芯片＝光发射机（电→光、产生并调制光信号），探测器芯片＝光接收机（光→电）。橙色段为电信号、蓝色段为光信号——两端的光芯片完成"电↔光"全链路转换。
两种集成方式：① 传统模块＝激光器芯片封进 TOSA、探测器芯片封进 ROSA，再与电芯片（DSP/Driver/TIA）组装；② 硅光模块＝取消分立 TOSA/ROSA，用外置 CW 激光器芯片 + 高集成硅光芯片（PIC）协同收发。（对应前面"光引擎"模块里 TOSA/ROSA → PIC/EIC 的演进）
② EML 和 CW 到底差在哪？——"自带调制" vs "只给光"
关键区别一句话：EML 自己就能调制信号，CW 只提供一束恒定的光、把调制让给别人（硅光 PIC）做。注意 CW（Continuous Wave 连续波）不是和 DFB/EML 并列的结构，而是"工作模式"——硅光用的 CW 光源本质是一颗大功率 CW DFB 激光器（同属 InP）。
图：EML 把 DFB 激光区与 EAM 调制区做在同一颗 InP 芯片内，电数据直接驱动 EAM 调制——自带调制、单片集成，故壁垒/成本最高；CW 激光器只负责发恒定连续光，调制交给另一颗硅光芯片上的 MZM 完成——激光器结构简单、外延链短、良率更优，但需更高输出功率。

📦 顺带定义"硅光模块"：把调制器（MZM）、波导等集成到一颗硅光芯片（PIC）+ 外置 CW 激光器收发，区别于传统模块的分立方案（EML 封 TOSA、探测器封 ROSA、逐颗组装）。一句话：硅光把"调制"从 InP 的 EML 搬到硅芯片的 MZM，但"发光"仍靠外置 InP CW——替代的是 EML 调制器、不是 InP 激光光源（这也是 InP 地位稳固的根本原因）。
↗ 注意"硅光"是技术轴（引擎用什么做），和"位置轴"（可插拔/NPO/CPO）正交：把这颗硅光引擎从可插拔搬到 ASIC 旁/封装内就是 NPO/CPO——详见上方 CPO 章节「🔆 光引擎」模块。
投资含义：EML（尤其 200G）短缺背景下，"CW + 硅光"成 AI 数据中心替代首选；英伟达已分别向 Coherent、Lumentum 各投资约 20 亿美元锁定 CW 产能。CW 国产化差距比 EML 更小、是率先导入点：源杰（70/100mW 批量、300mW 突破并拟投 12.51 亿扩产）、长光华芯（70/100mW 量产、200mW 验证）、仕佳光子（75-1000mW 矩阵）、永鼎鼎芯（70mW 量产）；但 CPO 所需 300mW+ 高功率 CW 国内仍在验证/研发。
③ 一颗光芯片是 100G 还是 200G？由什么决定
模块总速率 ＝ 单波速率 × 通道数　｜　单波速率 ≈ 波特率（Baud）× 调制阶数（每符号 bit）
当前主流调制是 PAM4（4 电平、每符号 2 bit），所以 50GBaud×2＝100G、100GBaud×2＝200G。100G→200G 单芯片升级，本质是把单通道波特率从约 50GBaud 提到约 100GBaud（PAM4 下 Nyquist 频率从 28GHz 翻到 56GHz）——对芯片调制带宽、外延工艺、色散容忍度、温控（EAM 对温度敏感、需 TEC）要求大幅提高，这就是 200G EML 壁垒更高的原因。

④ InP 的角色：不可替代的核心衬底，也是当前最紧的瓶颈
InP（磷化铟）是光通信光芯片不可替代的核心衬底：CW、DFB、EML 边发射激光器 + PIN/APD 探测器都做在 InP 上（GaAs 只做短距 VCSEL）。关键是——即便硅光加速渗透，硅光自己不发光、仍要外置 InP 激光器，所以 InP 激光光源地位长期稳固。当前 InP 80% 以上需求来自 AI 数据中心。
市场地位
2025 全球光芯片市场 ~$40 亿：InP 58% / 硅光 32% / GaAs 10%；2031 扩至 ~$150 亿，InP 占比降至 46%（仍约 69 亿）。硅光渗透但 InP 光源地位稳。
供需 / 价格
衬底缺口 >70%、持续到 2028；寡头垄断（住友 42%/北京通美 36%/JX 13%，CR3~91%）；2 英寸价从 2025 初 ~$800 涨到 $2300-2500（+250%），急单破 $3000。
为什么扩不出来（核心壁垒）：① 高纯铟受限（90% 来自锌冶炼副产、中国管制，2026 起铟出口锁定年产量 30% 内）；② 设备卡脖子（外延 MOCVD 由 AIXTRON 主导~80%、交期 7 月+、美国对华管制；晶体炉、EBL 交期超 12 月）；③ 扩产周期 18-36 月 + 8-12 月良率爬坡 + 下游认证数月至一年。
